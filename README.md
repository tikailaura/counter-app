A simple passenger counter app built with HTML, CSS, and JavaScript.

## Features

- Increment passenger count
- Save previous counts
- Display saved entries
- Reset the counter

## Built With

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Practiced

- Variables
- Functions
- DOM manipulation
- Event handling
- String manipulation
